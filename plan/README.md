# PMS ISO Review Plan Set

This plan set is the evidence-backed baseline for correcting Ovid PMS against the applicable ISO foundations. Existing planning documents remain useful design context; the two files below are the authoritative current assessment and implementation order produced from code tracing.

- [ISO-to-code assessment](./00-iso-pms-assessment.md) — standards basis, architecture map, numbered findings F-001–F-015, affected layers, dependencies and acceptance criteria.
- [Role and capability matrix](./role-capability-matrix.md) — observed role views/actions, ISO-aligned target authority, project-scope and segregation findings.
- [Implementation roadmap](./implementation-roadmap.md) — dependency-ordered work packages from build/security foundation through governance, control, records and UX.

The assessment is deliberately read-only: no application source code was changed during the review.
